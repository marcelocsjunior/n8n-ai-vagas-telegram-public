# Workflows n8n

Este diretorio deve armazenar exports sanitizados dos workflows n8n.

## Regras

Antes de subir um workflow exportado:

1. Remover credenciais.
2. Remover tokens.
3. Remover identificadores pessoais sensiveis.
4. Remover links privados.
5. Validar se o arquivo nao contem segredos.

```text
agente-vagas-ia-local-telegram.json
```
